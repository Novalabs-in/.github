# Support Policy 💬

Welcome to the Novalabs-in community! Whether you are a developer integrating our tools or a user encountering an issue, we want to help you get the support you need.

Please review the guidelines below to choose the best support channel for your question.

---

## 🧭 Support Channels & Guidelines

| Channel | Purpose | Where to Access |
| :--- | :--- | :--- |
| **Documentation** | First place to look for guides, setup, and FAQs. | Check the `README.md` of each individual repository. |
| **GitHub Discussions** | General questions, configuration issues, design ideas, and community chat. | [Novalabs-in Discussions](https://github.com/orgs/Novalabs-in/discussions) |
| **GitHub Issues** | Reporting reproducible bugs or proposing concrete feature enhancements. | Create an issue in the specific project repository using our forms. |
| **Security Reports** | Reporting security vulnerabilities privately. | Email `security@www.saitejabandaru.com` (see our [Security Policy](SECURITY.md)). |

---

## ⚡ How to Ask a Great Question
To help us resolve your issue or answer your question quickly, please:
- **Search first**: Check if your question has already been answered in the repository's issues, pull requests, or Discussions.
- **Provide context**: Detail your operating system, programming language/runtime version, and library versions.
- **Provide logs or code**: Include code snippets, configuration files, and terminal logs wrapped in markdown code blocks.
- **State expectations**: Describe what you expected to happen, and what actually happened instead.
